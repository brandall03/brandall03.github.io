# Benjamin Randall Portfolio Website

This is a simple static portfolio website for GitHub Pages.

## Files

- `index.html` is the website content.
- `style.css` controls the website design.
- `resume.pdf` should be your resume PDF.
- `images/` is where project images can be added later.

## GitHub Pages setup

1. Create a GitHub repository named `yourusername.github.io`.
2. Upload `index.html`, `style.css`, `resume.pdf`, and the `images` folder.
3. Go to the repository settings.
4. Open `Pages`.
5. Set the source to deploy from the `main` branch.
6. Open `https://yourusername.github.io` after GitHub finishes publishing.

## Things to edit

- Replace the GitHub and LinkedIn placeholder links in `index.html`.
- Add real project images into the `images` folder.
- Update project descriptions as your work changes.
